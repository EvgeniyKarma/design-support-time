# Учёт работы — онлайн версия

Это приложение для личного учёта времени по клиентам. Интерфейс размещается на GitHub Pages; зашифрованные данные сохраняются в приватном репозитории `EvgeniyKarma/design-support-time-data` в файле `vault.json`.

## Доступ к данным

- На каждом устройстве требуется fine-grained personal access token с доступом только к репозиторию `design-support-time-data` и разрешением `Contents: Read and write`. Не включайте разрешение Workflows.
- Для расшифровки используется парольная фраза от 12 символов. Пароль не отправляется в GitHub и не сохраняется приложением. Если пароль утерян, расшифровать файл будет невозможно.
- По желанию токен можно запомнить на устройстве: приложение сохраняет его только в зашифрованном виде под вашим паролем.
- Репозиторий данных должен оставаться приватным. В историю Git попадают только зашифрованные версии файла.
- Для переноса прежних браузерных записей скачайте JSON-резервную копию в локальной версии, войдите в онлайн-приложение, нажмите «Восстановить» и выберите файл.

GitHub Pages — публичная страница; она не содержит клиентских записей. Не добавляйте PAT или резервные копии в этот репозиторий.
